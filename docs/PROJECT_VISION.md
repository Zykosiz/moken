# Moken — Project Vision

## Vision

Moken is a stylized adventure RPG built around sailing between isolated islands in a world where supernatural Horrors have severed the sea itself. The player begins alone, nearly dead, guided only by a mysterious pistol that reacts to the Horrors.

The game is not about surviving the end of the world.

It is about reconnecting it.

---

# Design Pillars

## 1. Every Voyage Is An Adventure

The sea is the connective layer of the world. Every destination should feel like a discovery rather than another level.

## 2. Civilization Survives

Safe islands, towns and great cities still exist. The world is wounded and isolated, not destroyed.

## 3. Horrors Must Be Memorable

Every Horror should feel like a major event.

Each Horror may distort reality differently:
- Camera perspective
- World geometry
- Navigation
- Visual presentation
- Gameplay rules
- Audio

Players should never know exactly what the next Horror will do.

## 4. Restore Connections

Defeating a Horror restores part of the surrounding sea, allowing trade, travel and communication to return.

## 5. Small Crew, Great Journey

The story begins with one exhausted survivor in a tiny boat and gradually grows into a voyage shared with an unlikely crew.

---

# Guiding Principle

Whenever a design decision is made, it should strengthen at least one of these pillars. If it does not, it should be questioned before becoming part of the game's canon.
